## Trial protocol

1. Record Node/npm/OS and the exact reviewed commit or verified tarball checksum.
2. Install cleanly, run the passing fixture and capture the exit code.
3. Run the deliberately broken fixture and verify the case/pointer diagnostic and
   exit 1. Check blocked launch without consent and optional snapshot/diff.
4. Report setup time, confusing instructions, missing safety expectations and any
   minimal reproducible defect using synthetic data only.
5. If using an owned server, review its effects independently and use disposable,
   read-only credentials. Decide separately whether any result may be published.

A publishable case study must include participant consent, exact versions,
reproduction commands, observed outcomes, limitations and attribution approval.
Until an independent participant completes this, external validation is pending.
