# CLI languages

The CLI supports English (`en`) and Simplified Chinese (`zh-CN`). All owned help,
human report labels, contract diagnostics, safety errors and operational errors
use a typed catalog. Flags, command names, tool names, JSON pointers, schema
keywords, assertion values and server content retain their original values.

Selection order is the last `--lang` argument, nonempty `MCPCL_LANG`, `LC_ALL`,
`LC_MESSAGES`, `LANG`, the system locale, then English. Both `--lang=zh-CN` and
`--lang zh-CN` work before or after a subcommand. Scanning stops at `--`.
Empty environment variables are ignored. An unknown selected locale quietly
falls back to English. Explicit empty values also select English. `zh`, `zh_CN`,
`zh-Hans` and `zh-Hans-CN` select Simplified Chinese; encoding and modifier suffixes
are removed. Other locales select English.

`test` defaults to localized console output. `inspect` and `diff` retain JSON
as their default; `--report console` selects their human view. Snapshot success
messages and stderr errors are localized. Machine JSON and JUnit retain canonical
English diagnostics, existing schemas and status/classification enums. Snapshot
files are identical across languages. Localization metadata lives outside report
objects and is never serialized. Opaque server and user strings are not translated.

Exit codes remain 0 (success), 1 (contract or compatibility failure), 2 (configuration
or operational failure), and 3 (safety block). Locale selection never grants launch,
network or tool-call permission. Secret redaction applies after human translation;
console output contains no ANSI escapes, including with `NO_COLOR`.

The 4 MiB report guard is evaluated against the canonical English representation.
If translation alone exceeds that budget, only the human presentation is truncated
at a UTF-8 boundary, with a localized notice and final summary retained. The result
and exit code do not change. Machine report limits remain unchanged.

This change provides CLI localization only. It does not add an HTML interface,
publish packages or translate protocol/server data.
